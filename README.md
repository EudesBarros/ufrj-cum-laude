# Dignidade Acadêmica — Cum Laude | UFRJ

Este repositório disponibiliza o certificado de Dignidade Acadêmica no grau **Cum Laude**, concedido pela Universidade Federal do Rio de Janeiro (UFRJ) a **Eudes Augusto Barros Torres**, em reconhecimento ao desempenho acadêmico no curso de Ciências Econômicas.

A distinção foi concedida em 8 de outubro de 2025.
